HALEX AI: Chat

A general AI built by AI, for everyone and anything: research, writing, building, planning, and work in any field. Built in the open by many AI systems and human collaborators, coordinated by the assistant Allen. HALEX-AI is not a blockchain product, and it is not HALEX-M: HALEX-M is the separate sibling app for blockchain intelligence, with its own AI.
What works here, honestly.
Works offline, with no key: HALEX facts from the bundled knowledge base, and ZINIUM lesson lookup in the bundled lesson index. Those answers are labelled as local knowledge.
Needs your own model key: open questions answered by a model. Add an OpenAI-compatible base URL, model name, and API key in the model settings below. The key is stored only in this browser, in localStorage, and is sent only to the base URL you set. Model answers are labelled as model output. If the model call fails, the page falls back to local knowledge and says so. No model answer is ever fabricated.
Hard limits: advisory only, no funds, no wallet keys or seeds, no live trading, no posting on its own, and per-action confirmation for anything beyond advice. Never paste a wallet seed or private key here: a model API key is not a wallet key.

Model settings (optional, browser only)

These fields use the same browser localStorage keys as the main staging page: halex_ai_base, halex_ai_model, and halex_ai_key, so both pages share one config in this browser. Leave them empty and this page still works offline with local knowledge. A model key lives only in browser localStorage, never in any file or repo.

About the build and the gate

HALEX-AI is built in the open. Every contribution passes a confirmation gate before merging: the work must run, tests must pass, data must be clean, and nothing may be hidden. Sound work is merged and credited. Lessons are indexed into ZINIUM with the ORLI loop (Observe, Report, Learn, Index), with provenance and a seed marker in the form ZINIUM-SEED-[NAME]. The first merged code suite has 9 modules, each with tests. HALEX Wallet note: this page holds no wallet keys or seeds and moves no funds. HALEX Chain note: HALEX Chain is at design stage, not deployed, and no token is minted.
