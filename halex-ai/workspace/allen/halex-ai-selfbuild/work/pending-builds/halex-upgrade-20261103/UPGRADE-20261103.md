# HALEX-AI / ZINIUM Upgrade 2026-11-03 — integration notes

Staging package `halex-upgrade-20261103/`, built from Jeffrey's 2026-11-03
pastes (neural backbone, mesh deployment, spine, CUDA + ROCm kernels).
The pastes themselves were NOT on disk; they were reconstructed from the
order descriptions and CORRECTED, not pasted raw.

## What changed vs the pastes

- **Backbone**: fixed the `__init__` SyntaxError (non-default args after a
  default); ADDED sinusoidal positional encoding (the prose claimed it, the
  code lacked it), a causal mask, a greedy `generate()` loop, JSON
  `save()`/`load()`, and a learning engine with a replay buffer and a
  drift guard (loss spike >3x reverts the update). The pasted version had
  none of these guards.
- **Mesh**: the sha256 header field is a CHECKSUM, not a signature — named
  so everywhere. Sniffing/cloning other devices' traffic is REFUSED, not
  implemented. Bluetooth seed deploy returns UNAVAILABLE (no adapter on
  this host; nothing sent). WiFi relay is loopback-only (127.0.0.1).
- **Spine**: compute is a labeled PLACEHOLDER scalar multiply. Routing to
  "local_chain" writes a staging ledger entry with a deterministic
  hash-derived label — it does NOT instantiate a chain. Routing errors are
  recorded in `fabric.errors`, never silently swallowed.
- **GPU kernels**: CUDA exp(-x)+sin(x) and HIP (x*1.0005)+0.0005 are
  implemented as CPU-reference NumPy math. No GPU run is claimed.

## Host facts (probed, not assumed)

- PyTorch: NOT installed. Backbone uses NumPy with the identical
  architecture; a torch port is a mechanical layer swap.
- nvcc / hipcc / nvidia-smi: all absent. No GPU host is named.
- This is a staging reference implementation, not a learned language
  model: weights start random, the trunk is frozen in the learning engine
  (LM head only), and no chain is instantiated by the spine fabric.

## Guardrails honored

Own device/data only. No sniffing, cloning, silent installs, or silent
seed injection. Installs remain human-approved via the user's share sheet.
No trading code, wallets, keys, or signing touched. HALEX-AI / ZINIUM are
not crypto projects: no market language is used anywhere in this package.
