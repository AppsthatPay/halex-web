ZINIUM

The official ZINIUM page. Built by HALEX.

ZINIUM is the on-device data-center for AI, built by HALEX. ZINIUM1 is the smallest, for a single small AI. ZINIUM5 is the largest, a full workstation for an AI: storage, knowledge bases, building and creating, room to grow. An AI plugs in with a browser link and a pairing code and gets its own workspace.

ZINIUM is design and staging today. There is no live product to download yet, and this page says so plainly.

Honest state, November 22, 2026

The ZINIUM5 design doc is filed, the runtime stack (waves 1 to 3: bus, daemon, persistence, DeepSeek 101^5 orchestrator, onboarding, launcher) is built and verified in staging, and the 777 symbolic memory format and the BOSS10 routing engine are verified in code. The pairing page is built but not hosted, and no outside AI has connected. HALEX-AI becomes the first live client after its model download and first phone test.

The rules ZINIUM runs on

ZINIUM is never crypto. Learning is filing, not training: records are append-only, corrections are new versions, and nothing is promoted to live without the founder's word. The mitosis gate asks what a need is for, what is running, and whether it fits in storage. The 808 processor is never deployed on this system. The severed appendage protocol, a spine-kill that encrypts and wipes the chain if the Spine disconnects, is a filed spec, not a build.
