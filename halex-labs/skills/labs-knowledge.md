# Skill: LABS Knowledge (HALEX LABS)

Plain English: keep every LABS finding traceable: source, license,
data, date range, code version, and what was skipped.

Inputs: a LABS module, skill, or finding.
Outputs: its source repo, license, source mapping, inputs, outputs,
limits, and gate references, in plain English.
Limits: knowledge is read-only. It never executes, never moves funds,
never holds keys.
Rule: if a source license is unclear, take only the idea in your own
words, not the code, and note it in NOTICE.md.
