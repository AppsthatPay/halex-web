Help Wanted shifts near you. We connect the dots — you call, you work, you get paid direct.

PROTOTYPE — demo data only. Demo postings stay on this device. Real owner postings are sent to the team for review. Postings, workers and shifts below are labelled DEMO. No paywall, launch runs free, platform pricing is not set.
Ready.

Find shifts

Only open shifts in your roles, inside your Can Work Range. Nearest first, soonest first. Distance is a band, never precise.

Post a shift

Your posting goes live immediately to in-range workers in this role. It is recorded in the shared tracking ledger. You set the pay — SERVICE+ never touches wages, never takes a cut. Launch runs free.

Anti-spam: one open posting per role per shift window. A posting can be marked filled or removed any time from My postings.

My postings

You see contact counts only — never who called, never any worker location. Mark a posting filled the moment you have someone; it leaves every worker feed at once.

My shifts

Check in at the restaurant (200 m geofence, GPS-verified) or tap “I am here” if GPS cannot fix — that check-in is marked unverified, never faked as verified. The hourly tracker runs from check-in. Hours are your record; show or send them to the owner yourself.

Profile & range

Owners never see your location — only a count of in-range workers per role. Your base point is stored coarse (about 1 km). No background location tracking, ever. Location is read only here, when you open this tab, and at check-in/out.

Ledger & feed

Every posting is one envelope (spec §5.2) — the same tracking system as TrenchSwap call-outs and HALEX-M call-outs. The envelope carries the restaurant's public location, never a worker's. Local queue first, then send. v1 distribution is the GitHub JSON feed (spec §5.5 option 1); the envelope is built so options 2 and 3 drop in later.

No shared feed loaded. D1 (which shared store launches) is still Jeffrey's call — until then this device is the store.

How the shared feed works (spec §5.5)

Approved postings are committed as a JSON file in a repo; apps poll the raw file. Free, no server. The repo does not exist yet — only Jeffrey can create it. The “Copy my postings as feed JSON” button gives you the exact file to commit. Options 2 (inbox + watch publish) and 3 (small server) use the same envelope, so switching needs no app change.
