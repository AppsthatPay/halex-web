# PrototypeM — HALEX-M sandbox build

Working preview of the HALEX-M app (built 2026-10-18). Open `index.html`
in a browser, or serve the directory.

## What's inside

11 tabs: Home, APEX¹ (live market feed via GeckoTerminal + DexScreener),
APEX² (watchlist + research lab with live impersonation/vamp checks), RUSTY
(6-step token mint flow, 11 chains, rust/ember branding + red wolf emblem),
News, Trading (real AI wallets + measured skillsets), Research (SolHaG
REAL/SUSPECT/MIMIC verdicts), Chaintarium (Three.js 3D planetarium),
AI Sockets, Security (UXSS/SHELL gates), Wallet (connectivity preview).

## Honesty rule

Live data where free public APIs allow (market feed, token detail, research
checks, 3D). Anything not wired yet — trade execution, wallet signing,
agent pairing, game-engine layers — says so on its face. Nothing pretends.
